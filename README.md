# Digit recognition model
Simple AI model for recognizing digits, trained and tested with the MNIST dataset.

## Requirements:
- Python 3.14.x
- numpy
- PyTorch (torch & torchvision)
- matplotlib
- pathlib
- tomllib
There are no API keys in this project.

## Training
The repository does not contain any saved trained models, but the model was trained and tested.
The model was trained with the following specs:
- GPU: NVIDIA GeForce RTX 3050 8GB
- CPU: AMD Ryzen 5 5600x 6-Core Processor
